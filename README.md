# Altered TCG — Print-Ready Card Files

![Card assembly preview](promo/FUGUE_promo.gif)

This repository contains print-ready card files for the [Altered TCG](https://altered.gg) card game, generated from official card data released by Equinox.

## What's in here

Each folder is organised by set, then by card family:

```
<SET>/
└── <card-family>/
    ├── cards.pdf          # all rarity variants of this card, print-ready
    ├── ALT_..._C.jpg      # Common variant preview
    ├── ALT_..._R1.jpg     # Rare variant preview
    └── ALT_..._R2.jpg     # Rare (R2) variant preview
```

## Printing

These PDFs are ready to hand directly to your local print shop. Key specs:

- **3 mm bleed margins** included on all sides — standard for card printing
- **CMYK colour space** — correct for professional print workflows
- **Card size:** 63 × 88 mm (standard poker/TCG size)

Just bring the PDF for the card(s) you want, ask for **poker-size card printing on thick cardstock**, and the bleed margins will be handled automatically by the printer.
